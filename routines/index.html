Make a plan with AI

Ask ChatGPT, Claude or any AI assistant for a plan that fits you, then open it in LWYL.

  1. Copy the prompt below and fill in the parts in [brackets].
  2. Paste it into the AI and send.
  3. Save its answer as a file called plan.lwyl (ask the AI to “give it to me as a file”, or paste it into a note and share it as a file).
  4. Open the file on your iPhone and choose LWYL.
Create a workout plan for the LWYL app as one JSON file (I'll save it as plan.lwyl).

About me:
- Goal: [build strength / lose fat / run a 10K …]
- Days per week: [3]
- Equipment: [full gym / dumbbells and a bench / bodyweight only]
- Experience: [beginner / intermediate / advanced]
- Start date: [YYYY-MM-DD], plan length: [4 weeks]

Use exactly this format:
{
  "unit": "kg",
  "templates": [
    {
      "name": "Push Day",
      "notes": "optional",
      "schedule": ["YYYY-MM-DD", "YYYY-MM-DDTHH:MM", { "date": "YYYY-MM-DD", "time": "HH:MM", "note": "Deload" }],
      "exercises": [
        { "name": "Barbell Bench Press", "muscleGroup": "Chest",
          "sets": [ { "reps": 8, "weight": 60, "restSeconds": 120 } ] },
        { "name": "Cable Lateral Raise", "muscleGroup": "Shoulders",
          "sets": { "count": 3, "reps": 12, "weight": 10 } },
        { "name": "Plank", "muscleGroup": "Core", "sets": { "count": 3, "seconds": 45 } },
        { "name": "Running", "muscleGroup": "Other", "sets": [ { "km": 5 } ] }
      ]
    }
  ]
}

Rules:
- One entry in "templates" per different workout; list every day it's planned on in its "schedule".
- muscleGroup is one of: Chest, Back, Legs, Shoulders, Arms, Core, Other.
- Use common exercise names (e.g. "Romanian Deadlift", "Pull-Up", "Dumbbell Bicep Curl").
- Weights in kg. Timed sets use "seconds", distance uses "km".
- Reply with only the JSON, no explanation.

The format

A routines file is plain JSON saved as .lwyl (or .json, imported from Routines › Import). One file can hold many routines.

Routines and exercises

Each routine in templates has a name, optional notes and its exercises. Exercise names are matched to LWYL’s library of 600+ exercises; anything else is added to your own exercises under its muscleGroup (Chest, Back, Legs, Shoulders, Arms, Core, Other).

Sets

Either a list — [{ "reps": 8, "weight": 80 }, …] — or a short form — { "count": 3, "reps": 12, "weight": 10 }. Timed sets use seconds, distance uses km. restSeconds is optional; without it, LWYL uses your Rest Timer settings.

Schedule

schedule lists the days a routine is planned for: "2026-10-19", "2026-10-19T07:30", or { "date": "…", "time": "18:00", "note": "Heavy" }. Dates are local. With a time, LWYL reminds you an hour before; without, at your morning reminder time. Past dates are skipped.

Units and names

unit is "kg" or "lb" for the whole file. Importing never overwrites: a routine whose name you already have is added as “Name (2)”.
